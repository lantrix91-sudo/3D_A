# Инструменты

`old/e2e_*.py` — устаревшие сценарии прототипа: порт 4173, demo-banner и прежний интерфейс. Перенесены без изменения; это архив, а не действующая проверка приложения. Указанные в них команды и пути могут не работать после переноса.

`e2e_server_pose.mjs` проверяет серверную расстановку и меняет данные. В рамках уборки не запускался; использовать только на тестовой базе.

`pdf_to_layout.py` и `glb/` оставлены на месте. Тесты текущего frontend: `npm test`; проверка типов: `npm run typecheck`.
