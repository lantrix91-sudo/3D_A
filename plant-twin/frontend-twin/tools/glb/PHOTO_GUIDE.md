# 3D-модель оборудования по фотографиям

Модели строятся в чате с Claude: вы присылаете фото и размеры, получаете файл `.glb`, загружаете его
в двойнике через «Данные и 3D-модель» (или при добавлении оборудования).

## Что прислать

1. **Фото со всех сторон**: спереди, сзади, слева, справа, сверху (если можно), и 2–3 фото под углом 45°.
   Снимайте целиком, без сильного перспективного искажения (с 2–3 м, не вплотную).
2. **Габариты**: ширина × глубина × высота в мм (из паспорта или рулеткой). Это главное для точного масштаба.
3. **Табличка (шильдик)** крупно: марка, модель, серийный номер.
4. Крупно — характерные узлы: пульт, двери, дежа, бункер, транспортёр, вытяжка.
5. По желанию: размеры отдельных узлов (высота стола загрузки, диаметр дежи и т. п.).

## Что получится

- Упрощённая, но узнаваемая модель: основные объёмы, двери, пульт, характерные узлы, цвета корпуса.
  Это не фотограмметрия и не CAD-модель производителя.
- Масштаб — метры, низ модели на полу, лицевая сторона смотрит вперёд (+Z). Размер файла обычно 20–200 КБ.
- Если нужна точная копия, подойдёт модель производителя (STEP/IGES → конвертация в GLB) или
  фотограмметрия (Polycam, RealityScan и т. п. → экспорт GLB).

## Как это устроено

Модель описывается кодом на three.js из готовых примитивов (`tools/glb/kit.mjs`: корпус, цилиндр, бункер,
ролики, опоры, материалы) и собирается в GLB:

```bash
node tools/glb/build.mjs tools/glb/models/<модель>.mjs models/<модель>.glb
```

Пример — `tools/glb/models/sample-divider.mjs` (условный тестоделитель для проверки загрузки).
В наборе есть надписи простым блочным шрифтом (`label('MIWE', 0.075, материал)`, `tools/glb/font.mjs`:
A B D E G I M W, r o l i n, дефис) и патрубок дымохода с тёмным отверстием (`chimney(...)`).
Новые буквы добавляются в `font.mjs` по мере надобности.
Скрипт печатает габариты готовой модели — их сверяют с паспортными.

## Анимация: чтобы было видно, что оборудование работает

GLB-файл сам по себе статичен. Двойник оживляет модель по **именам узлов** — это соглашение `anim-*`.
Модели, которые делаются здесь по фото, сразу размечаются так; в Blender достаточно переименовать объект.

| Имя узла | Что делает двойник | Пример |
|---|---|---|
| `anim-rotate` | вращает узел вокруг его вертикальной оси (1 оборот за 24 с), пока оборудование работает; плавный разгон и выбег | тележка ротационной печи, дежа |
| `anim-spin` | быстрое вращение (2 об/с) | вал, спираль, мешалка |
| `anim-glow` | свечение материалов: ярче с ростом температуры, после остановки медленно гаснет | свет и жар пекарной камеры |
| `anim-status` | окрашивается в цвет состояния (работает / предупреждение / авария / нет связи…), мигает при тревоге | световая полоса, сигнальная лампа |
| `anim-screen` | экран светится, пока есть связь | дисплей пульта |
| `anim-bowl` | вращение дежи тестомеса (~12 об/мин), пока оборудование работает | дежа |
| `anim-orbit` | планетарная головка: обход дежи (~40 об/мин); инструмент кладётся внутрь как `anim-spin-rev` | головка планетарного миксера |
| `…-rev` | суффикс: вращение в обратную сторону (`anim-spin-rev`, `anim-bowl-rev`, `anim-rotate-rev`) | спираль против дежи |
| `anim-display` | дисплей светится только во время работы, гаснет при остановке | сенсорная панель вакууматора |
| `anim-progress` | полоса хода цикла растёт слева направо (30 с), пока идёт работа; опорная точка — левый край | шкала цикла на дисплее |
| `anim-steam` | точка (пустой объект), из которой идёт пар, пока оборудование работает | вытяжка на крыше печи |

Ось вращения — собственная ось Y узла, поэтому узел `anim-rotate` должен стоять началом координат в центре
вращения (у тележки — в центре камеры). Если в GLB есть встроенные анимации (Blender → Export glTF → Animation),
двойник проигрывает их, пока оборудование работает, и останавливает при остановке.
