# Живая индикация в сцене

Перед запуском примените `python manage.py migrate` из `backend`.

В Django admin:

- `EquipmentType.key_signals`: JSON-список до двух ключей, например
  `["temperature", "power"]`. Миграция заполняет существующие типы числовыми
  сигналами из шаблонов, предпочитая temperature/power. Новые типы настраиваются вручную.
- `Asset.rotation_speed_deg_s`: скорость вращения в градусах/секунду, 0 выключает.
- `Asset.animation_node_name`: имя дочернего узла GLB; пустое поле включает поиск
  `rotor`, затем `tray`. Вращается локальная ось Y только у работающего оборудования.
  Корневая группа с координатами оборудования не вращается.

Палитра и текстовые статусы — `frontend/src/scene/colors.js`. Переход цвета занимает
0.3 с; alarm пульсирует с периодом 1.2 с, run слегка меняет яркость с периодом 2.4 с.
Системная настройка reduced motion отключает пульсацию и вращение, включая её
изменение без перезагрузки страницы.

`VITE_STALE_SECONDS=120` в окружении frontend задаёт порог устаревания при сборке.
После него корпус и светодиод сереют, в подписи появляется возраст данных в минутах.
Исходный серверный статус не перезаписывается; карточка сохраняет последний известный
статус и отдельно предупреждает об устаревании. При новых данных цвет восстанавливается.

Подписи содержат код, текстовый статус и до двух значений с единицами. Их текст
обновляется не чаще раза в секунду. Видны выбранный/наведённый объект и объекты
ближе половины обзорной дистанции камеры. Скрытые зоны не участвуют в выборе.

История: `GET /api/v1/equipment/<code>/readings/?hours=1`, с прежней JWT-авторизацией
для operator/engineer/admin. Ответ содержит `equipment`, `start`, `end`,
`bucket_seconds: 60`, `series: [{key, name, unit, points: [{x, y, min, max}]}]`.
`x` — Unix-секунды начала минуты, `y` — среднее исправных измерений. Ошибки датчиков
не участвуют в среднем/экстремумах. Полностью неисправная минута имеет null-значения.
Параметр hours допускает целые значения 1–24. История не меняет endpoint приёма данных.

Панель загружает Chart.js по требованию, показывает один выбранный числовой сигнал
и обновляет историю каждые 30 секунд. Tooltip содержит минимум/максимум минуты.
Смена выбора/выход уничтожает график и таймер; запоздалый ответ не меняет новую панель.
Доступно текстовое описание графика, значения и время обновления.

Для производительности геометрия/текстуры ассетов остаются общими, материалы
переиспользуются внутри корпуса и отдельно внутри LED. Между экземплярами материалы
независимы, чтобы переходы и устаревание одного станка не меняли соседние. Шейдер
обесцвечивания общий, параметр задаётся на материал. Статичная сцена не перерисовывается;
анимации используют один цикл, HTML обновляется только при изменениях.

Проверка в браузере: переключить пять статусов, приблизить камеру/навести курсор,
выбрать станок и сигнал графика, отключить телеметрию на 120 секунд, затем возобновить.
В DevTools Rendering включить prefers-reduced-motion и проверить остановку движения.
Проверка 60 объектов в headless Chromium проверяет поведение, но не заменяет замер
FPS на ноутбуке с реальными GLB.
