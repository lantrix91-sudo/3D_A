## Критично

### C1. Резервная база отслеживается Git

- **Где:** `backend/db.sqlite3.bak` — бинарный файл, номера строки нет; подтверждён `git ls-files backend/db.sqlite3.bak`, размер 233472 байта.
- **Проблема:** резервная БД попадает в репозиторий. Она потенциально содержит пользователей, хэши паролей и производственные данные; наличие конкретных записей не проверялось. Уже добавленный файл не исключается последующим правилом `*.bak`.
- **Предложение:** проверить содержимое в закрытом окружении, убрать из индекса, оценить очистку истории и доступы к копиям. Если найдены реальные учётные данные — отозвать/сменить затронутые секреты. Удаление файла из последнего коммита не очищает историю.

### C2. Офлайн-осмотры могут уйти на другой сервер и от другого пользователя

- **Где:** `mobile/src/offline/queue.js:22`, `:115`; `mobile/src/main.js:176`, `:217`, `:230`; `backend/rounds/services.py:246`.
- **Проблема:** общая IndexedDB `plant-twin`, у записи нет server/user. После смены сервера очередь сохраняется; после выхода и нового входа отправляется текущим api-клиентом. Backend записывает request.user как inspector. Совпадение кода станка на другом сервере позволяет записать осмотр не туда; смена аккаунта меняет авторство. Предупреждение settings это не предотвращает.
- **Предложение:** разделить очередь, черновики, кэш и токены по адресу сервера и user.id; фиксировать владельца при создании записи. Не досылать запись при несовпадении контекста; дать экспорт/возврат к исходному аккаунту без потери фото. Сервер должен проверять контекст, а не доверять произвольному inspector из JSON.

### C3. Android допускает передачу пароля/JWT по HTTP

- **Где:** `mobile/src/api/server.js:4`, `:17`; `mobile/android/app/src/main/res/xml/network_security_config.xml:7`; `mobile/src/api/client.js:43`, `:64`.
- **Проблема:** умолчание — конкретный LAN-IP по HTTP; отсутствие схемы превращается в http; Android разрешает cleartext для всех хостов. В такой конфигурации пароль и bearer-токены передаются без шифрования. Критично при реальном использовании; настройки развёрнутого сервера неизвестны.
- **Предложение:** HTTPS по умолчанию и обязательный HTTPS в release, запрет cleartext либо ограниченное исключение только в debug. Адрес производства задавать конфигурацией, убрать частный IP из release-умолчания.
